Technical Overview

Omnivore is a document ingestion pipeline designed for Postgres-native RAG systems.

It processes documents through format-specific handlers and stores results in PostgreSQL.

Supported Formats

Phase 1 supports PDF, DOCX, TXT, Markdown, HTML, JSON, CSV, and XLSX files.

Phase 2 will add audio, video, and image OCR capabilities.

Storage Model

All extracted content is stored in PostgreSQL with pgvector support for embeddings.

Extracted tables and row data enable direct SQL querying alongside vector search.
